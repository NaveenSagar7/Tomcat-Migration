Automated a Microservices-Based Flask Application on AWS
Deployed a modular Flask web application with login, player, and frontend microservices using EC2, Nginx, and Gunicorn. Integrated Aurora MySQL with read replica for high availability, S3 + CloudFront for static content delivery, and Lambda for S3-triggered database updates. Implemented CI/CD with CodeDeploy and automated infrastructure provisioning with Terraform and IAM-based access control.

AWS Services Used: EC2, ALB, Auto Scaling, Aurora MySQL (writer & read replica), S3, CloudFront, Lambda, IAM, CodeDeploy, VPC, NAT Gateway, CloudWatch, Terraform.
